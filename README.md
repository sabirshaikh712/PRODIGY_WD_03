# 🎮 Tic Tac Toe Game (Web)

Live Demo :- https://sabirshaikh712.github.io/PRODIGY_WD_03/

This is a **Tic Tac Toe web application** built using **HTML, CSS, and JavaScript**.  
The game supports **Two Player mode** as well as **Player vs Computer mode** with multiple difficulty levels.

---

## 📌 Features

- ✔️ Classic 3×3 Tic Tac Toe board  
- ✔️ Two Player mode  
- ✔️ Play against Computer  
- ✔️ Difficulty levels:
  - Easy
  - Medium
  - Hard
- ✔️ Turn indicator
- ✔️ Win & draw detection
- ✔️ Restart game option
- ✔️ Responsive UI

---

## 🛠️ Technologies Used

- **HTML** – Game structure  
- **CSS** – Styling and layout  
- **JavaScript** – Game logic and AI

## ▶️ How to Run

1. Download or clone this repository  
2. Open `index.html` in any web browser  
3. Start playing immediately  

👉 No installation or server required

---

## 🎮 Game Modes

### 👥 Two Players
- Both players play on the same device
- Turns alternate between **X** and **O**

### 🤖 Vs Computer
- Computer plays as **O**
- Difficulty options:
  - **Easy** – Random moves
  - **Medium** – Winning & blocking logic
  - **Hard** – Minimax algorithm (smart AI)

---

## 🔁 Controls

- Click on any cell to make a move
- Use buttons to:
  - Switch game mode
  - Change difficulty
  - Restart the game
